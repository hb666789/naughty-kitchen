# 🍳 胡闹厨房 · 菜谱管理系统

一个可爱风的做饭网页系统，纯前端实现，数据全部保存在浏览器本地（localStorage）。

## ✨ 功能

- 📖 **菜谱管理**：自定义添加菜式（配料清单、烹饪时间、烹饪方式、难度、做法、配图）
- 🖼️ **配图上传**：自动压缩后保存
- 🎁 **盲盒抽菜**：随机选一道菜，解决"今天吃什么"
- 🧺 **点菜系统**：点单清单 + 数量增减
- 👩‍🍳 **做菜模式**：烹饪倒计时 + 配料/步骤打勾清单 + 进度条
- ✅ **做菜打卡**：打卡记录 + 连续天数 + 最近 14 天日历
- 👥 **厨师档案**：多位厨师各管各的菜谱，可自定义头像/昵称/口号
- 🌦️ **天气推荐**：自动定位城市 + 当日天气，按冷暖/雨雪智能推荐菜式

## 🚀 使用

直接打开 https://hb666789.github.io/naughty-kitchen/ 即可（需联网获取天气，需允许定位权限）。

纯 HTML / CSS / JavaScript，无任何构建步骤与后端依赖。
